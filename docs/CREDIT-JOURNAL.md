# 逐响应积分记录

桥接在收到流式响应的 `usage.credit` 后，将积分和响应标识追加到 `DSH_HOME/storages/dsh-connect-workbuddy/response-credits.jsonl`。状态栏等读取端可用响应标识关联会话记录。

## 记录格式

每行包含一条 JSON 记录：

```json
{"v":1,"r":"response-example","c":0.12,"a":"account-example","t":1793808000000}
```

| 字段 | 含义 |
| --- | --- |
| `v` | 格式版本，目前为 1 |
| `r` | 上游响应标识 |
| `c` | 该响应的 `usage.credit`，包含零积分 |
| `a` | 实际处理该请求的账号标识，使用桥接现有的账号标识算法 |
| `t` | 写入时间，单位为毫秒 |

记录包含上述五个字段。读取端按响应标识去重；会话归属通过会话记录中的响应标识确定。

## 账号切换与重试

正常响应绑定处理请求的账号。账号池切换后，记录使用切换后的账号标识。

工具调用格式恢复触发重试时，原响应和重试响应分别记录其扣分。重试期间再次切换账号时，重试响应绑定新账号。

缺少响应标识、非数字积分、负数积分及非有限数值会被忽略。文件写入异常通过日志报告，响应转发继续执行。

## 中文提示

中文设置说明、错误信息和工具说明按功能、状态、操作及费用编写。设备来源使用“本机设备”和“虚拟设备”区分；涉及收费的操作明确标注积分消耗。
