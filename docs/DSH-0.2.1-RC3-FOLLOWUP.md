# DSH 0.2.1-rc.3 兼容性复核

复核日期为 2026-10-24，环境为 Node 24.21、pnpm 11.28.5。本文记录 rc.3 升级时的接口对照和模型标签界面扩展位置修复。

## 1. 依赖与加载

插件的 13 个直接依赖中，12 个包的库文件保持一致，primitives 存在增量。对 313 个包的构建产物进行比较时，大部分差异来自版本号替换；rc.2 到 rc.3 的功能变化集中在 conversation、plugin-manager、primitives 和 web-app。被移除的 3 个包均未被本插件引用。

DSH 版本检查使用 includePrerelease: true，因此现有版本范围允许 rc.3 加载。该结果也更正了 [rc.1 调查](DSH-0.2.1-RC1-FOLLOWUP.md)对预发布版本的早期判断。

## 2. 模型标签界面扩展位置冲突

model.label 是单组件界面扩展位置，多个注册者使用相同优先级时会发生冲突。插件原优先级为 0，与官方组件的注册发生冲突，触发 1017 错误。

修复将插件优先级改为 -0.5。当时 qoder 使用 -1，DSH 使用 0；界面扩展位置选择数值最低的注册者。这个规则也意味着其他插件可能先于本插件显示标签。

插件按 DSH 提供的注册接口传入标签。曾评估的代渲染方案会发生递归并触发 RangeError，因此未采用跨插件枚举和代渲染方式。

## 3. 验证记录

model-label-slot-coexistence.spec.tsx 当时包含 6 项检查，覆盖注册优先级和共存约束。完整测试结果为 2225 项通过、2 项跳过，类型检查和构建通过。

这些结果对应本次升级的依赖与源码版本。后续版本应重新核对界面扩展位置类型、优先级规则及注册者；检查方法见[设计文档](DESIGN.md)。
