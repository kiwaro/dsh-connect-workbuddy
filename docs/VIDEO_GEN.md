# 视频生成

本页说明视频工具的参数、输入图片要求及任务结果的读取方式。

工具 `workbuddy_draw_video` 使用已授权区域的 WorkBuddy 账号生成视频。先在所用区域开启模型供应商及“允许模型调用视频生成工具”，再由会话模型调用。两个区域都启用时，插件优先使用国内版。

插件提交任务后，查询生成状态，并在任务完成后下载视频。一次调用可能持续几十秒至几分钟。费用按所用账号、模型及生成参数结算，最终扣分从任务完成结果中的 `credit` 读取。

## 1. 参数与模式

提供 `prompt` 可生成文生视频；增加一张 `image` 输入图后，插件使用图生视频模式。输入图支持绝对路径、file URL、HTTP URL、data URL 或 base64 字符串，也支持仅含一个字符串的数组。

| 参数 | 规则 |
| --- | --- |
| `prompt` | 必填非空字符串，最多 2500 字符 |
| `image` | 可选，每次一张图片，上限 8 MB |
| `model` | 可选，模型需属于所用区域和生成模式 |
| `seconds` | 可选数字，默认 5 秒；目录或已知规则提供时长范围时按范围校验 |
| `resolution` | 可选字符串，例如 720P、1080P；省略时采用默认值 |
| `aspect_ratio` | 文生视频可用，支持 16:9、9:16、1:1，默认 16:9 |
| `negative_prompt` | 可选字符串，最多 2500 字符 |
| `enable_audio` | 可选布尔值，默认 true |

图片输入由插件读取或下载，再编码为 data URL。远程图片使用 GET 下载，超时为 30 秒。需要多图参考时，可先用图片工具合成一张输入图，再通过 `image` 提交。

图生视频的比例由输入图决定，插件省略 `aspect_ratio`。可选参数提供错误类型时，工具返回 `INVALID_ARGS`。

## 2. 默认模型与目录校验

插件按以下顺序选择模型：

1. 本次调用明确指定的 `model`。
2. 设置页为该区域和模式保存的 `preferredVideoModels`。
3. 对应媒体标签组中的第一个模型。

明确指定的模型需要通过目录校验。已保存的默认模型下架后，插件改用标签组中的第一个模型，设置页显示默认选项。

文生视频使用 `text-to-video` 标签组，图生视频使用 `image-to-video` 标签组。媒体目录缓存 5 分钟，设置页可重新读取。修改默认视频模型后，插件保存配置，再读取配置以核对写入结果。

模型目录可提供 `videoGeneration`：

| 字段 | 用途 |
| --- | --- |
| `minSeconds`、`maxSeconds` | 校验时长范围 |
| `defaultSeconds` | 目录中的默认时长信息 |
| `resolutions` | 可选分辨率列表，匹配时忽略大小写，发送目录中的拼写 |
| `defaultResolution` | 请求分辨率超出已知列表时采用的默认值 |

目录缺少相应约束时，插件将参数提交到 WorkBuddy 校验。服务端返回可解析的时长范围后，插件按区域和模型记录该范围，用于本进程后续请求的校验。

## 3. 提交、查询和下载

| 阶段 | 接口或结果 |
| --- | --- |
| 提交 | `POST /v2/videos/generations`，读取 `data.id` |
| 查询 | `POST /v2/videos/tasks`，请求体包含 `task_id` |
| 完成 | 读取视频 URL 和最终积分 |
| 下载 | GET 视频 URL，保存到系统临时目录的 `workbuddy-video-gen/` |

公共请求字段包括 `prompt`、`model`、`seconds`、`negative_prompt` 和 `watermark: true`。图生视频增加图片字段，分辨率与声音选项放在 `extra_parameters` 中。请求头使用 `imageHeaders()`。

查询间隔为 5000 毫秒。任务返回 `failed` 时报告失败；其他未完成状态继续查询。完成结果包含有效视频 URL 后，插件下载视频并返回 `.mp4` 文件的 `file://` 地址。

### 3.1 超时

| 计时层 | 上限 |
| --- | --- |
| 视频查询循环 | 540000 毫秒 |
| 插件工具调用 | 570000 毫秒 |
| DSH 工具调用 | 600000 毫秒 |
| 单次视频下载 | 120000 毫秒 |

工具和查询超时早于 DSH 上限，便于错误信息保留任务标识。下载和提交仍受上层剩余时间限制。

## 4. 输出、费用与错误

输出包含下载地址及生成参数，字段为 `videos`、`mode`、`model`、`prompt`、`seconds`、`resolution` 和 `hint`。服务端提供扣分时，输出增加 `credit`。其中 `videos` 包含下载文件的 URL。

提交成功表明服务端已受理任务，最终费用在任务结果中读取。提交后的查询、生成或下载失败也可能涉及已经受理的任务，因此应凭任务标识核查处理结果。

| 错误类别 | 处理方式 |
| --- | --- |
| `INVALID_ARGS` | 修正参数或输入图片 |
| `NOT_LOGGED_IN` | 登录并检查区域授权 |
| `NO_VIDEO_MODEL` | 刷新目录并选择对应模式的模型 |
| `AUTH` | 更新登录凭据 |
| `RATE_LIMIT` | 等待恢复 |
| `NO_ROUTE` | 检查该区域的视频接口 |
| `REJECTED` | 提交请求被参数等校验拒绝，按服务端提示调整 |
| `TASK_FAILED` | 根据任务错误排查 |
| `POLL_TIMEOUT` | 保留任务标识，检查任务后续状态 |
| `EMPTY_RESULT`、`UPSTREAM` | 检查响应字段和服务端详情 |

工具独占执行。请求提交后的适用失败触发 60 秒冷却。请求提交前的校验失败可在修正后立即重试；提交返回 `REJECTED` 时，调整被拒绝的参数后也可立即重试。

服务端曾对 `seconds: 1` 返回 `code 14407`，并给出 `supported range: 4-15 seconds`。插件将这个范围记录在 `learnedSeconds` 中，下次可在提交前检查同模型的时长。

## 5. 代码与测试

`src/video-tool.ts` 负责工具参数、模型选择、执行及输出；`src/video-gen.ts` 负责协议参数和响应解析；`src/upstream.ts` 负责传输、查询及下载。凭据由 DSH 端读取，工具结果提供视频路径和业务信息。

测试见 `tests/video-gen.spec.ts`、`tests/video-tool.spec.ts`、`tests/video-tool-optin.spec.ts`。测试检查两种生成模式的参数与目录选择，并验证错误处理、执行时限和区域授权。图片输入处理说明见 [IMAGE_GEN.md](IMAGE_GEN.md)。

## 6. 历史测量：2026-10-25

原测量版本为 4.13.2，提交 `dfe7ab3`。国内版目录包含 `kling-video-v3` 与 `minimax-video-h3`，国际版记录包含 `kling-video-v3`。调用时以所用账号返回的媒体目录为准。

### 6.1 扣分

以下成功任务均设置 `enable_audio: true`：

| 模式 | 模型 | 请求时长 | 实扣积分 | 折合每秒 |
| --- | --- | --- | --- | --- |
| 图生视频 | `minimax-video-h3` | 4s | 57.14 | 14.29 |
| 图生视频 | `kling-video-v3` | 4s | 68.57 | 17.14 |
| 文生视频 | `minimax-video-h3` | 5s | 71.43 | 14.29 |
| 文生视频 | `kling-video-v3` | 5s | 128.57 | 25.71 |

该记录中，`minimax-video-h3` 两种模式的每秒费用均约为 14.29；`kling-video-v3` 两种模式的费率不同。不同区域使用各自积分，价格比较需要同时注明模式和模型。

### 6.2 文件规格

| 产物（本地时间） | 请求 → 实际时长 | 帧数 | 分辨率 | 视频码率 | 音轨 | 体积 |
| --- | --- | --- | --- | --- | --- | --- |
| `11-12-24` | 5s → 5.086s | 121 | 1280×720 | 11.47 Mbps | AAC 0.13 Mbps | 7.0 MB |
| `11-50-20` | 4s → 4.459s | 107 | 1344×768 | 3.66 Mbps | AAC 0.13 Mbps | 2.0 MB |
| `11-59-51` | 4s → 4.042s | 97 | 1280×720 | 7.93 Mbps | 无 | 3.8 MB |
| `12-03-59` | 5s → 5.167s | 124 | 1344×768 | 5.45 Mbps | AAC 0.13 Mbps | 3.4 MB |

产物标识按当时的生成时间记录。文件与模型的对应关系未随响应固定保存，因此文件规格按生成时间列出。

该轮文件为 H.264 视频，约 24 fps，部分包含 AAC 音轨。设置 `enable_audio: true` 的任务中也出现过无音轨文件。播放器应读取实际音轨和时长信息。

按 24 fps 计算，121 帧视频约为 5.042 秒，107 帧约为 4.458 秒，97 帧约为 4.042 秒，124 帧约为 5.167 秒。容器还可能计入音轨时长。记录中的分辨率为 1280×720 和 1344×768，码率范围为 3.66 至 11.47 Mbps。后续处理应采用文件解析结果。

原记录还发现，旧实现缺少目录分辨率列表时会丢弃显式分辨率；现有规则区分“目录提供列表”与“目录缺少列表”，按第 2 节处理。
