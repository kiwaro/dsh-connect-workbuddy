布局调整说明

对应上面四行标记

1. 按钮对齐　签到、测试放在左侧；重新检测放在右侧，两组按钮共用一行。

2. 模型来源　在目标测试模型设置中显示指定、免费或自动状态。

3. 头部信息　成员表显示账号，设置行显示目标模型，头部保留标题和当前账号徽标。

4. 保存区域　保留底部操作布局，保存按钮仍用于提交偏好设置。
